# 【医学常识】专栏| 如何辨别真假“胸痛”？

> 更新时间：2026-09-16 (UTC+8)

编者按

 张阿姨最近总觉得“胸痛”，怀疑是心脏出了问题，不过，经医生仔细询问及检查，确定了张阿姨只是胃部及食道的问题。想必有很多人会有这样的疑问，明明有心慌和胸前区不适感，为什么不是心脏的问题呢？之所以会出现这样的情况，是跟它的位置有关系。心脏位于胸腔中部偏左下方，横隔之上，两肺间偏左，所以当出现胸部不适时，普通人很难辨别是哪里出了问题。今天，空军特色医学中心心血管内科东楼病区与本公众号编辑部联合开设的“修心坊”专辑就来跟大家聊一聊都有哪些疾病跟胸痛有关系。

**胸痛是一个常见症状，其临床意义可轻可重，先来看看跟心脏有关的胸痛会有哪些症状？****
**1. 心绞痛与胸痛

心绞痛是由于冠状动脉供血不足，导致心肌急剧的、暂时的缺血缺氧所引起的。分为稳定型心绞痛和不稳定型心绞痛。疼痛部位多位于胸骨中上段后，放射至左肩、臂内侧、颈肩等，性质多呈压迫感、紧缩感、烧灼感、频死感，持续时间多为3-5分钟，诱发因素多为体力活动、情绪激动等，经休息或消除诱因后，症状可缓解。原为稳定型心绞痛，如果近1个月内发作频繁，硝酸酯类药物效果差，或者一个月内新发心绞痛，较轻运动或劳动即可诱发以及休息状态下发作，就可转变为不稳定型心绞痛。此外，老年人和糖尿病患者对于胸痛不敏感，多感觉用力后气短而不是胸痛，有的患者仅表现为牙痛。

2. 急性心肌梗死与胸痛

若胸痛剧烈且持续，时间超过30分钟，常表现为烦躁不安、出汗、恐惧或有濒死感，休息和含用硝酸甘油片多不能缓解。也有少数无疼痛，一开始即表现为休克或急性心力衰竭。如果出现这些症状就可能是急性心肌梗死，即使胸痛缓解，也应尽快就诊，以明确诊断，因此心梗发生的胸痛是高危胸痛之一。

3. 主动脉夹层与胸痛

多数主动脉夹层患者胸痛好发于剧烈活动时，开始时胸痛特别剧烈，并伴有大汗淋漓。若夹层发生的部位离心脏很近，当出现剧烈胸痛后，动脉很快破裂使患者胸痛后立即死亡；若夹层发生的部位离心脏较远，剧烈胸痛后可转为胸闷，继而出现腹痛、腹胀等症状，说明夹层继续向下延伸，非常凶险，此种胸痛也被列为高危胸痛。

4. 急性心包炎与胸痛

心包是包在心脏外面的一层薄膜，心包和心脏壁的中间有浆液，能润滑心肌，使心脏活动时不跟胸腔摩擦而受伤，心包炎是由各类原因引起心包炎症反应的一类疾病。心包炎引起的疼痛性质多为刺痛、钝痛、酸痛、闷痛等，常见的为胸膜性刺痛，起病迅速，发作突然。初发心包炎患者的疼痛持续时间从半小时到1天不等且呈持续性发作的表现。同时吸气和咳嗽时疼痛加重，有时在变换体位或吞咽时出现或加重。

5. 心脏神经官能症与胸痛

胸痛部位常位于心尖区及左乳房下区，常为刺痛或隐痛，可持续数秒或数小时，常伴有胸闷、气短、心悸等症状。此种胸痛多于紧张、激动后诱发，与体力活动无关，常在休息时出现，活动或转移注意力后减轻。

**此外，还有其它一些疾病也会出现胸痛，让我们一起也来了解一下：**
**1****肺栓塞**

胸痛症状不明显，是由内源性或外源性栓子栓塞肺动脉引起肺循环障碍的临床和病理生理综合征。有些人在深吸气或咳嗽时出现，有的人在活动时出现，多数病人活动时伴有胸闷、气短、干咳等症状，由肺栓塞引发的胸疼也属于高危胸痛，一定要重视。其发病率仅次于冠心病及高血压；死亡率居第三位，仅次于肿瘤及心肌梗死。

**2****自发性气胸**

表现为不剧烈的一侧胸痛，可于活动时或咳嗽时出现，多见于瘦高的健康年轻人，或有慢性肺部疾病的患者，多发生于持重物、屏气、剧烈活动或咳嗽后，患者突感胸闷气短，且程持续性，严重者可危急生命。

**3****肺癌**
患者可出现胸痛，并于呼吸、咳嗽时加重。除胸痛外，患者可出现刺激性咳嗽、胸闷气短、咯血，并伴有消瘦、乏力等表现。

**4****肺炎胸膜炎**
患者有上呼吸道感染使，伴有发热、咳嗽、咳痰，甚至胸闷气短。

**5****反流性食管炎**
胸痛表现位于胸骨后的烧灼样痛，多在饱餐后平卧位或弯腰时出现，可伴有反酸、烧心、反胃等症状。

**6****肋间神经痛**
多存在精神紧张、情绪不稳及睡眠差等诱因，表现为胸部或背部针刺样痛，持续数秒或数分钟后可自行缓解。

**7****非化脓性肋软骨炎**
疼痛部位多发生在胸骨旁第2-4肋软骨，以第2肋软骨最常见，单侧或双侧均可累及，疼痛为钝痛或锐痛，局部有明显触痛，严重者可因上肢活动或咳嗽等动作使胸痛加重，胸痛持续时间较长，可达数小时。

**我们还可以根据胸痛发生的部位来判断是哪种疾病：**
1. 心前区：多见于心绞痛、心肌梗死、心包炎。
2. 胸骨后痛：多见于心绞痛、急性心梗、心包炎、纵膈疾病、食管疾病。
3. 一侧胸痛：多见于胸壁、胸膜、肺部疾病。
4. 后背痛：除脊柱疾病外，主动脉夹层也可以发生。

**那么，生活中发生急性胸痛又该怎么办呢?**
1. 急性胸痛发生后需要立即就地坐下或躺下休息。
2. 身边如备有硝酸甘油可以立即舌下含服一片，看胸痛是否能马上缓解。
3. 如果不能缓解的要立即拨打120或999急救电话，绝不能走回家或走到医院，以免发生猝死等严重事件。

综上所述，能够引起胸痛的疾病很多，如果发生了胸痛，千万不可大意，需要根据伴随症状、体征等综合判断。心梗、主动脉夹层、肺栓塞、自发性气胸引发的胸疼都属于高危胸痛，当您无法辨别请及时就医，以免耽误病情。
