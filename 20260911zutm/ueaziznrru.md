# 儿童荨麻疹图片

> 更新时间：2026-09-11 (UTC+8)

概述

儿童荨麻疹临床表现为扁平的高出皮肤的风团、红斑或者丘疱疹，伴随剧烈瘙痒。

儿童荨麻疹多是过敏反应所致，常见原因首先是食物，以蛋白食物为主。其次是药物，还有可能是由感染引起。
症状
小儿在患病早期会出现皮肤发痒现象，继而出现全身性大小不等的风团，扁平高于皮肤，形状不规则，但边缘清楚。颜色发白或是发红，越起越多，逐渐蔓延。或是表现为出现红斑伴有明显的瘙痒。部分患儿会出现发热，乏力，关节痛以及腹痛等全身症状。疾病发生和消退迅速，消退后不留任何痕迹。

病因

儿童荨麻疹主要是过敏反应导致的。最常见的病因是食物过敏，以蛋白食物为主。其次考虑药物和疫苗的原因。除此之外，感染如细菌、病毒、寄生虫等也会引起荨麻疹，如上呼吸道感染等疾病一年四季均可成为荨麻疹的诱发因素。蚊虫叮咬也是常见因素之一。
诊断
儿童荨麻疹具有典型的临床表现，根据皮疹表现为风团和红斑伴随瘙痒，再结合饮食和用药史即可判断。必要时结合实验室血清过敏原特异性lgE测定和过敏原检测。
治疗
以病因治疗及对症治疗为主，明确病因后进行饮食管理或环境药物过敏原的控制，急性发病可口服药物，主要是H1抗组胺药氯雷他定，根据儿童的年龄和体重不同，用药量不同。瘙痒症状可以外用炉甘石洗剂进行止痒，有明显感染的儿童使用抗生素控制感染。同时。若小儿发病急骤，伴随呼吸困难，声嘶、喘息等症状，提升发生喉头水肿，必须立即入院就医，即刻给肾上腺素，配合糖皮质激素进行急救治疗。
